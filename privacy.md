# Privacy Policy

This application is a personal tool used by the owner to synchronize files between the owner's Google Drive and iCloud Drive using rclone.

## Google User Data

The application accesses Google Drive data only for file synchronization requested by the owner.

Google user data is not sold, shared, or disclosed to third parties.

OAuth credentials and tokens are stored locally on the owner's computer by rclone. This application does not operate a separate server that stores Google Drive file contents.

Access is used only for synchronization of the owner's files.

## Contact

For questions regarding this privacy policy, contact the application owner through the support email shown on the Google OAuth consent screen.
